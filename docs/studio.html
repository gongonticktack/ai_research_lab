GPUモデルを使うには

Linux / WSL2のリポジトリ内で bash scripts/setup-studio.sh、次に bash scripts/start-studio.sh を実行し、表示されるローカルURLを開いてください。画面のボタンから各モデルの環境をインストールできます。SF3Dのモデル重みにはHugging Faceでの利用条件への同意・認証が必要です。

ブラウザ版の骨格検知はモデルを初回に自動読み込みし、画像は外部へ送信しません。GPU生成の重み取得や処理には時間がかかる場合があります。
