# AI Research Lab

This repository is a lightweight research lab for benchmarking 3D AI models such as SAM 3D Body, validating experimental results, and publishing structured performance insights through a dashboard and GitHub Issues.

It focuses on reproducible evaluation, data validation, and result aggregation for 3D computer vision experiments.

リポジトリ: [ai_research_lab](https://github.com/gongonticktack/ai_research_lab) / [ダッシュボード](https://gongonticktack.github.io/ai_research_lab/)

3D・AI研究の自動実験ラボ。共通JSON → 検証 → 集計 → Three.js表示 → 実測の性能変化をIssue化する最小構成です。
